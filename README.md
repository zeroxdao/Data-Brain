# Data-Brain

DATA BRAIN —— 面向交易员与 EA 自动交易系统的 AI / ML 交易大脑。

定位：**知识库 + 策略工厂 + 风控调度大脑**，用于信息处理、策略生成与验证、
风险管理以及基于市场环境的 EA 自动调度。

## 设计文档

完整、可落地的实现蓝图见：

- [`docs/DATA_BRAIN_设计文档.md`](docs/DATA_BRAIN_设计文档.md)

## 核心功能

1. **功能1 - 策略工厂**：按需求生成候选策略 → 真实回测 + 前向验证 + 过拟合检测 → 生成可直接运行的 EA。
2. **功能2 - 环境感知调度**：抓取 MT4/MT5 交易历史，用 ML 学出"什么市场环境用哪个 EA"，并自动切换。

## 重要前提

MT4/MT5 无法在网页直接登录 broker 运行，需通过 **MetaApi** 或 **自建 VPS + 桥接 EA**
作为执行层；网站是"指挥中心"，MT 终端是"执行器"。详见设计文档第 0 节。
